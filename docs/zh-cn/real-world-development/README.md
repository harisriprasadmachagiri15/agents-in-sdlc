通过真实场景、完整应用和共享待办事项，了解 GitHub Copilot 如何融入软件开发生命周期。你将迭代规划修改、编写代码、测试行为、审查拉取请求并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，提供面向开发者的棋盘游戏众筹平台。团队的待办事项已经整理为 GitHub 议题，可供你处理，其中包括筛选和分页等功能开发，以及无障碍和编码标准等质量改进。

## 选择工作环境

GitHub Copilot 可在不同工作环境中使用。选择适合自己开发方式的环境。每个工作坊都有独立的设置流程，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理助手。体验 Plan 和 Autopilot 模式、说明、技能、自定义代理、Playwright 模型上下文协议（MCP）、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行代理会话、切换会话模式、协作处理 Canvas，并管理 GitHub 议题和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub 议题分配给异步代理、引导其工作、监控进度并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
